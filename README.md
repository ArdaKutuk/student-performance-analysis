# Student Performance Analysis

This project analyzes the relationship between students' academic performance in Mathematics and Portuguese courses and various social and demographic factors.

The analysis focuses on how variables such as free time, family relationships, alcohol consumption, study time, and social activities may affect student success.

## Dataset

The project uses student performance datasets for:
- Mathematics course
- Portuguese language course

The datasets include:
- demographic information
- family background
- social behavior
- study habits
- academic grades

## Objectives

- Perform exploratory data analysis (EDA)
- Analyze correlations between variables
- Understand factors affecting student performance
- Apply basic data mining techniques

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
